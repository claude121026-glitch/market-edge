# Market Edge

Personal NSE screener: evening scan, macro news, global prices, corporate filings, morning watchlist,
live tracker and an honest paper-trading log. Runs on GitHub Actions; dashboard on Streamlit Community Cloud.

- Setup: [`market_edge/deploy/github/GITHUB_SETUP.md`](market_edge/deploy/github/GITHUB_SETUP.md)
- How it works: [`market_edge/README.md`](market_edge/README.md)

Screening output, not investment advice. The 1-year backtest found no proven edge after costs; paper-trade first.
